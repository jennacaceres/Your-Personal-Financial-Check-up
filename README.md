# Kumusta Pera Mo?
Personal financial wellness assessment by Jenna Guevara, CPA.

## Deploy
Upload `index.html` to a GitHub repository, import the repository into Vercel, and deploy. No build command or environment variables are required for this V1.

## Before publishing
Replace the booking-button placeholder in `index.html` with your real booking URL. This V1 does not transmit or store respondent information; all assessment processing occurs in the visitor's browser.
